# 杂交育种

将孟德尔遗传学引入 Minecraft。每一株小麦都有自己的基因型，育种、杂交、选优，培育属于你的超级小麦。

---

## 特性

- **6 对基因**：穗数、抗病、饱食、饱和、壳厚、生长速度
- **基因型与表型**：基因型默认隐藏，表型用石锄右键即可查看
- **配子**：成熟小麦掉落携带随机等位基因的雌、雄配子
- **杂交**：1 雌配子 + 1 雄配子在工作台合成新种子
- **自定义面包**：小麦基因决定面包是否额外回复饱食度、饱和度或两者
- **染病机制**：不抗病的小麦在生长早期有概率枯萎
- **自然生成**：打草、村庄农田等原版来源的小麦都会携带随机基因

---

## 玩法

1. 打草 → 获得杂交种子（随机基因）
2. 像原版小麦一样种在耕地上
3. 手持**石锄**右键成熟小麦，查看表型
4. 收获 → 获得杂交小麦 + 配子
5. 1 雌 + 1 雄配子 → 合成新种子
6. 用杂交小麦做面包，品质由基因决定

---

## 基因对照表

| 基因对 | 显性（大写） | 隐性（小写） |
|--------|-------------|-------------|
| A / a | 少穗 | **多穗** |
| B / b | **抗病** | 不抗病 |
| C / c | 低饱食 | **高饱食** |
| D / d | 低饱和 | **高饱和** |
| E / e | 多壳 | **少壳** |
| F / f | 生长不旺盛 | **生长旺盛** |

> 加粗表示育种中的"好性状"。注意大部分好性状是隐性的——需要纯合（`aa`、`cc`、`dd`、`ee`、`ff`）才能表现。

## 简单模式

管理员命令（需要 OP 等级 ≥ 2）：

```

/crossbreeding simple true    # 开启
/crossbreeding simple false   # 关闭

```

开启后，种子、小麦、配子的悬停提示会显示完整基因型。石锄右键时也会显示基因型。

状态保存在存档中，重启不丢。
